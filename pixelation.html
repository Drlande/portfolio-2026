Work / Pixelation study

Pixelation study

Technical study. A post-process material in Unreal Engine 5 that turns a 3D scene into pixel art. I built it and taught it to my class.

Class
CTK 305, October 2026
Engine
Unreal Engine 5, material editor
Scene
From our capstone

01

How it works

  1. Make a material set to Post Process.
  2. Read the frame with SceneTexture: PostProcessInput0.
  3. Split the screen into a grid: screen size ÷ Pixel Count. At 1920×1080, a Pixel Count of 4 gives 480×270.
  4. Snap each pixel to its block with Floor, so the whole block reads one color.
  5. Put it in a Post Process Volume set to Unbound.

02

Other looks

Fewer colors and dithering push it further. In our capstone this became the Style setting.

03

Problems I ran into

ProblemFix
No effectCheck the Post Process domain and that the volume is Unbound
Stretched blocksBuild the grid from ViewSize
Off by half a blockAdd 0.5 after Floor
Smearing when movingRun it after tonemapping
HUD stays sharpNormal. UI draws after post-processing

It doesn't make the game run faster. It's one more pass on top of the render.
